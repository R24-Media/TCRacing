# Contributing to TCRacing

Thank you for your interest in TCRacing.

## Current status

The repository is undergoing a licensing and third-party-content review. It is publicly visible, but it does not currently declare an open-source license. Until an appropriate license and contribution terms are published, please do not submit code or assets on the assumption that they can be accepted, reused, or redistributed.

You may use GitHub Issues to report reproducible project problems or suggest documentation improvements. Do not include confidential information, credentials, proprietary assets, or material you do not have permission to share.

## Before proposing a change

When contribution terms are published, please include:

- A concise description of the problem and proposed change.
- The Unreal Engine version and platform used.
- Reproduction steps and expected versus actual behavior for bug reports.
- Screenshots, logs, or a minimal test case where relevant, after removing sensitive information.
- Confirmation that submitted code and assets are your own or are shared under terms compatible with the project.

## Review

Changes may be reviewed for correctness, maintainability, compatibility with Unreal Engine 5.6, documentation, security, and licensing. A pull request is not accepted until it has been reviewed and explicitly merged by a maintainer.
