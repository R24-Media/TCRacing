# Security Policy

## Reporting a vulnerability

Please do not publish credentials, exploit details, personal data, or unpatched vulnerability details in a public issue.

Until a private vulnerability-reporting channel is configured for this repository, contact the maintainers through the private contact method listed on the R24-Media GitHub profile, or request a private reporting route in a public issue without including sensitive details.

Include the affected revision, Unreal Engine version, platform, impact, and minimal reproduction steps where safe to share.

## Supported versions

No formal supported-version policy has been established yet. The project configuration currently targets Unreal Engine 5.6; compatibility and security support for other versions are not guaranteed.

## Disclosure

Please allow the maintainer reasonable time to investigate and prepare a fix before public disclosure. Do not assume a report has been received until the maintainer confirms it.
